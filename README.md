🌐 Estudos & Projetos Django

💡 Django é um framework para Python que ajuda a criar sites e sistemas web de forma mais rápida e organizada. Ele já vem com várias ferramentas prontas, facilitando o trabalho dos desenvolvedores.

‼️ Esse repositório é voltado ao meu aprendizado Django. Aqui colocarei os projetos desenvolvidos por mim e projetos desenvolvidos junto com o professor durante as aulas, podcasts e explicações.

‼️ Os projetos que tenham no inicio da nomecratura "curso" foram desemvolvidos junto com o professor ao longo das aulas. E os que não contiverem no início "curso" são autorais.

No futuro eu pretendo colocar, junto com essa aba de Django, outros Flameworks Web Python: Flask, FastAPI, Pyramid, Web2py, Bottle, CherryPy, Tornado e Falcon.
